## 1、功能说明



1、按键说明：   

掌上stm版

```
      上键(B7)          跳跃键(B12)   功能键(B13)		屏幕：（SCL：B8）
													    （SDA：B9）
左键(B6)    右键(B4)

      下键(B5)          确定键(B14)   返回键(B15)
```

直插版

```
      上键(B12)          跳跃键(B5)   功能键(B7)		屏幕：（SCL：B8）
													    （SDA：B9）
左键(B13)    右键(B15)

      下键(B14)          确定键(B4)   返回键(B6)
```

 2、烧录所需的.hex文件在压缩包里，或在工程文件Object文件夹里。使用串口烧录软件将模块用数据线连接电脑烧录。

3、此程序包含游戏、时钟、设置功能

4、游戏包括：①恐龙跳、②贪吃蛇、③飞机大战、④俄罗斯方块、⑤双人乒乓⑥电子琴

5、工具包括：①倒计时、②秒表

6、设置包括：①静音设置、②光标设置、③动画速度

​       ④时间设置、⑤刷新时间

​      （设置的内容断电可记忆）

7、在菜单的主界面按返回进入停机状态并显示时间功能。

  （默认10s刷新一次，可在设置中设置）



## 2、游戏说明

1、恐龙跳：使用套件中的跳跃键（B12）跳。

2、贪吃蛇：使用左手边的四个方向键控制。

3、飞机大战：使用上下方向键控制飞机位置，使用跳跃键发射子弹；屏幕中至多只有3发子弹，超过3发子弹要等待装弹； 敌机碰到屏幕最左边时游戏结束。

​       ！！同时按下确定和返回键才能退出！！

4、俄罗斯方块：使用跳跃键使方块向左旋转，功能键方块向右旋转

​         下方向键方块加速向下。

5、双人乒乓：左边玩家使用上下方向键控制球拍位置；

​       右边玩家使用跳跃键控制球拍向上；功能键向下

​       没用球拍击中球的一方将会被缩短球拍长度，

​      球拍缩至最短时，游戏结束，另一方获胜。

6、电子琴：上键为1音节，左键为2音节，右键为3音节，下键为4

​       跳跃键为5，功能键为6，确定键位7，返回键为8；

​       同时按下确定和返回键才能退出。



## 3、工具说明

1、倒计时：左右键选择要设置的时、分、秒；上下键设置时、分、秒的长度 ；

确定键开始倒计时；倒计时结束时按任意按键可重置；

倒计时时可直接按返回键退出倒计时。

2、秒表：确定键开始计时，计时时按确定键暂停，暂停时按下键清零。



## 4、设置说明

1、静音设置：确定键选择是否静音。

2、光标设置：确定键选择光标样式。

3、动画速度：确定键选择动画速度。

4、时间设置：左右方向键选择需要设置的内容，上下键控制数值。

5、刷新时间：停机状态时间显示的刷新时间，按上下键选择数值(单位为秒s)。



## 5、代码说明

1、可以改动main函数里的时间数组，修改烧录后默认时间（建议在设置里修改）

2、可修改main函数中的`Time_Length`变量，修改停机状态下的刷新时间。

3、可在`menu_Data.c`中的`games_menu`数组按照格式 `{"游戏名"，函数名}` 加入游戏（游戏名应先用PCtoLCD2002软件按照格式进行汉字取模，放入`OLED_Data_Hanzi.c`文件中）。

4、按键以定义常量，可在`Key.h`里修改（确定和返回还要改中断线）。
