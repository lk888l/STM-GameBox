# 实机验收清单

编译通过只能证明类型、引脚映射、链接布局和静态资源成立。首次合入或更换 PCB/OLED 后，
请在 STM32F103C8T6 实物上记录以下结果。

当前连接设备的自动化结果见
[2026-09-02 实机测试报告](hardware-test-report-2026-09-02.md)；未勾选的肉眼、听感、
逻辑分析仪和受控掉电项目仍应按本清单完成。

## 烧录前

- [ ] 确认芯片确为 64 KiB Flash / 20 KiB SRAM 的 STM32F103C8T6。
- [ ] 确认 HSE 晶体为 8 MHz；若不同，先修改 `board.rs`，不要带错时钟试跑。
- [ ] PB8/PB9 到 SSD1306，地址 `0x3c`，总线上存在外部上拉。
- [ ] PA12 为无源蜂鸣器；若为有源蜂鸣器，需要替换声音策略。
- [ ] 保存当前旧固件和配置页备份。新固件会把最后两个 Flash 页用于自己的日志。

## 启动与显示

- [ ] 冷启动 20 次均出现扫描线、圆环、中文标题和进度动画，无随机花屏。
- [ ] 动画期间按任意键可立即进入主页。
- [ ] 用逻辑分析仪确认 I²C 约 400 kHz，数据阶段由 DMA 完成。
- [ ] 静止菜单不持续刷新总线；移动一项只发送发生变化的局部页。
- [ ] 临时断开再恢复 OLED（在安全断电条件下操作）后，固件不崩溃且能指数退避恢复。
- [ ] “动画关”无残影；慢/快动画均收敛，不抖动越界。

## 八键与手势

每个物理键单独执行至少 30 次，并记录误触/漏触：

- [ ] 轻按只产生一次单击语义。
- [ ] 两次短按在约 260 ms 窗口内只产生一次双击语义，不附带两个单击。
- [ ] 持续约 650 ms 只产生一次长按，随后方向/调整项按约 95 ms 重复。
- [ ] 按住一个键的同时操作另一个键，两者状态独立。
- [ ] 上电时按住任意键不会造成事件风暴。
- [ ] PB4 右键正常，同时 ST-Link SWD 仍可连接；JTAG 不应占用该脚。
- [ ] 连续快速操作后 RTT 的 `DROPPED_KEY_EVENTS` 仍为 0。

## 应用

- [ ] 贪吃蛇禁止直接反向，食物不生成在身体上，撞墙/撞自身进入结束状态。
- [ ] 得分后提示音播放且画面/按键任务不暂停；最高分重启后保留。
- [ ] 秒表在 `u32` 毫秒边界附近仍按预期累计（长期台架测试可加速时间 fake）。
- [ ] 倒计时调节、启停、归零提示和退出均正确；提示音期间按键仍响应。
- [ ] 软件待机时 OLED 低频更新，任意键唤回菜单。

## 持久化与掉电

- [ ] 修改设置后立即连续修改多次，只在停止操作约 750 ms 后产生一次提交。
- [ ] 重启后静音、动画、光标和刷新时间均恢复。
- [ ] 在擦除、写入、校验三个阶段分别做受控掉电测试，重启后至少一个快照有效。
- [ ] 擦写循环台架测试后没有越过 `0x0800_F800..0x0801_0000`。
- [ ] 固件更新工具不会执行全片擦除后再声称保留设置；需要保留时显式保护/备份两页。

## 性能记录

验收报告至少附上：固件 Git commit、release ELF 的 text/data/bss、I²C 单帧最大时间、
按键最坏响应时间、Flash 擦除期间最大可见卡顿、供电电压和 OLED 模块型号。
